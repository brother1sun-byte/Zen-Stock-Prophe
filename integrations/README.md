# Integrations

Only integrations evidenced by repository configuration are documented here:

- `github/`: source control and GitHub Actions validation.
- `render/`: Docker-based web hosting configured by `render.yaml`.
- `docker/`: reproducible frontend build and Python runtime image.
- `cloudflare/`: optional temporary development sharing via `cloudflared`.

There is no repository configuration for Slack, AWS, GCP, Vercel, monitoring, or error tracking, so no integration is claimed for them. Documentation does not authorize external calls, deployment, account changes, or secret entry.
